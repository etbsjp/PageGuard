ページ単位で BASIC 認証をかけられるプラグインです。ページごとに独立したユーザー名とパスワードを設定できます。

== Description ==

ページ単位で BASIC 認証をかけられます。サイト全体に1組だけではなく、**ページごとに独立したユーザー名 / パスワード**を設定できる点が特徴です。

= できること =

* ページ・投稿ごとに、保護のオン / オフとユーザー名・パスワードを設定できます。
* 保護中のページを、REST API・フィード・検索結果・アーカイブ・サイトマップからも除外します。
* 保護中のページのキャッシュを抑止します。

= ご注意 =

* **メディアファイルへの直リンクは保護できません。** 画像や PDF の URL を直接開かれた場合、この仕組みでは止められません。
* 設定済みのパスワードは再表示できません（ハッシュ化して保存しているためです）。

= 動作環境 =

* PHP 7.4 以上

WordPress のバージョン下限は設けていません。
