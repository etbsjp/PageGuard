# PageGuard

ページ単位で BASIC 認証をかけられる WordPress プラグインです。ページごとに独立した ID / パスワードを設定できます。

## 特徴

- **ページごとに独立した ID / パスワード** — サイト全体で 1 組だけの一般的な BASIC 認証プラグインと違い、保護したいページそれぞれに別の ID / パスワードを設定できます。「A 社にはこのページだけ、B 社には別のページだけ」といった渡し分けができます。
- **設定は投稿編集画面から** — 保護したいページの編集画面で ID / パスワードを入力するだけで有効になります。サーバーの `.htaccess` を直接編集する必要はありません。
- **保護する投稿タイプを選択** — 初期状態では固定ページだけが保護の対象です。プラグインの設定画面で、投稿やカスタム投稿タイプ（「お知らせ」「実績」など、テーマやプラグインによって追加された投稿の種類）でも、保護を設定できるようになります。
- **パスワードはハッシュ化して保存** — データベースには平文で保存しません（そのため、設定済みのパスワードを後から画面で読み出すことはできません。忘れた場合は再設定してください）。
- **編集権限があるユーザーは認証をスキップ** — そのページを編集できる権限でログイン中の場合は、認証を求められません。

### 保護できる範囲について

保護できるのはページ本体の表示と、そのページの内容を返す WordPress 側の経路（REST API・フィードなど）です。

また、保護されたページは、サイト内の検索結果から除外されます。WordPress が出力するサイトマップ（サイト内のページ一覧を検索エンジンに伝えるための XML ファイル）にも掲載されません。タイトルが一覧に並ぶことで、保護しているページの存在を推測されるのを防ぐためです。

ただし、除外できるのは WordPress が標準で出力する検索結果とサイトマップだけです。この除外には次の限界があります。

- **プラグインが独自に出力するもの** — 検索プラグインや SEO プラグインが独自に出力する検索結果・サイトマップには、タイトルが表示されることがあります。お使いのプラグイン側に、一覧から除外する設定がないかをご確認ください。
- **検索結果・サイトマップ以外の一覧** — アーカイブ一覧、カテゴリーやタグの一覧、最近の投稿ウィジェット、ナビゲーションメニュー、関連記事など、テーマやプラグインが出力する一覧にはタイトルが出ることがあります。テーマやプラグイン側に、一覧から除外する設定がないかをご確認ください。設定が見当たらない場合は、ナビゲーションメニューからリンクを外すなど、一覧に載せない運用をご検討ください。
- **保護をかける前に検索エンジンへ登録された情報** — Google などにすでに記録されているページの情報は対象外です。すでに公開していたページを後から保護する場合は、検索エンジン側での削除申請も併せてご検討ください。

なお、検索エンジンへの登録そのものは、ページを公開する前に保護を設定しておけば大きく減らせます。ただし、上に挙げた一覧にタイトルや URL が残っていると、そこから検索エンジンに見つかることがあります。機密性の高い内容は、公開後に保護をかけるのではなく、公開前に保護を設定しておくことをおすすめします。

**メディアファイルへの直リンク（画像・PDF などのファイル URL に直接アクセスされた場合）は保護できません。** これらのファイルは WordPress を経由せず Web サーバーが直接返すためです。URL を知っている人には見えてしまう点にご注意ください。機密性の高いファイルを扱う場合は、サーバー側の設定と併用してください。

なお、添付ファイルのページ（ファイル 1 つを表示する WordPress のページ）は保護されますが、対象は保護したページに**直接アップロードした**ファイルだけです。メディアライブラリから再利用したファイルの添付ファイルページは、保護の対象になりません。いずれの場合も、ファイル URL への直リンクは保護できません。

## インストール

### 管理画面から ZIP をアップロードする

1. 本リポジトリで配布している ZIP ファイルをダウンロードします。
2. WordPress 管理画面の「プラグイン」→「新規プラグインを追加」を開きます。
3. 画面上部の「プラグインのアップロード」をクリックし、ダウンロードした ZIP ファイルを選択して「今すぐインストール」を実行します。
4. インストール完了後、「プラグインを有効化」をクリックします。

### FTP / SSH でアップロードする

1. ZIP ファイルを展開します。
2. 展開してできた `pageguard` フォルダを、WordPress の `wp-content/plugins/` 配下にアップロードします。
3. WordPress 管理画面の「プラグイン」一覧で PageGuard を「有効化」します。

## 動作要件

| 項目 | 要件 |
| --- | --- |
| WordPress | 6.7 以上 |
| PHP | 7.4 以上 |

外部ライブラリへの依存はありません。

なお、BASIC 認証は毎回のリクエストで ID / パスワードを送信します。通信内容が第三者に読まれないよう、**HTTPS で運用しているサイトでのご利用を推奨します。**
