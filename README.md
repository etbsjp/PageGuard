# PageGuard

ページ単位で BASIC 認証をかけられる WordPress プラグインです。ページごとに独立した ID / パスワードを設定できます。

> **開発中です。** 現時点ではこの README のみで、プラグイン本体は未実装です。

## 特徴

- **ページごとに独立した ID / パスワード** — サイト全体で 1 組だけの一般的な BASIC 認証プラグインと違い、保護したいページそれぞれに別の ID / パスワードを設定できます。「A 社にはこのページだけ、B 社には別のページだけ」といった渡し分けができます。
- **設定は投稿編集画面から** — 保護したいページの編集画面で ID / パスワードを入力するだけで有効になります。サーバーの `.htaccess` を直接編集する必要はありません。
- **パスワードはハッシュ化して保存** — データベースには平文で保存しません（そのため、設定済みのパスワードを後から画面で読み出すことはできません。忘れた場合は再設定してください）。
- **編集権限があるユーザーは認証をスキップ** — そのページを編集できる権限でログイン中の場合は、認証を求められません。

### 保護できる範囲について

保護できるのはページ本体の表示と、そのページの内容を返す WordPress 側の経路（REST API・フィードなど）です。

**メディアファイルへの直リンク（画像・PDF などのファイル URL に直接アクセスされた場合）は保護できません。** これらのファイルは WordPress を経由せず Web サーバーが直接返すためです。URL を知っている人には見えてしまう点にご注意ください。機密性の高いファイルを扱う場合は、サーバー側の設定と併用してください。

## インストール

### 管理画面から ZIP をアップロードする

1. 本リポジトリで配布している ZIP ファイルをダウンロードします。
2. WordPress 管理画面の「プラグイン」→「新規プラグインを追加」を開きます。
3. 画面上部の「プラグインのアップロード」をクリックし、ダウンロードした ZIP ファイルを選択して「今すぐインストール」を実行します。
4. インストール完了後、「プラグインを有効化」をクリックします。

### FTP / SSH でアップロードする

1. ZIP ファイルを展開します。
2. 展開してできた `pageguard` フォルダを、WordPress の `wp-content/plugins/` 配下にアップロードします。
3. WordPress 管理画面の「プラグイン」一覧で PageGuard を「有効化」します。

## 動作要件

| 項目 | 要件 |
| --- | --- |
| WordPress | 6.7 以上 |
| PHP | 7.4 以上 |

外部ライブラリへの依存はありません。

なお、BASIC 認証は毎回のリクエストで ID / パスワードを送信します。通信内容が第三者に読まれないよう、**HTTPS で運用しているサイトでのご利用を推奨します。**
