# PageGuard

ページごとに別々の ID とパスワードを設定して、そのページだけを閲覧制限できる WordPress プラグインです。

> **本プラグインは開発中（未リリース）です。** 以下は予定している内容で、プラグイン本体はまだ含まれていません。

## 特徴

- **ページごとに独立した ID / パスワード** — サイト全体で 1 組を共有するのではなく、保護したいページ 1 枚ごとに別の ID とパスワードを設定できます。取引先ごとに別々の資料ページを渡す、といった使い方ができます。
- **BASIC 認証で保護** — 保護したページを開くと、ブラウザ標準の ID / パスワード入力ダイアログ（BASIC 認証）が表示されます。専用のログインページは作りません。
- **保護する投稿タイプを選べる** — 既定は固定ページのみ。設定画面で他の投稿タイプも対象にできます。
- **そのページの編集権限を持つログイン中のユーザーは、入力を求められずそのまま閲覧できます。**

### 保護できる範囲

保護できるのは、WordPress が生成して返すページの内容（HTML の表示、REST API、フィード、検索結果やサイトマップへの掲載）です。

**メディアライブラリにアップロードしたファイル（PDF・画像など）の URL を直接開かれた場合は保護できません。** これらのファイルは WordPress を通さず Web サーバーがそのまま返すため、プラグイン側では止められないという仕組み上の制約です。URL を知られると誰でも開けるので、ページ本文に貼るファイルの内容にはご注意ください。

## インストール

1. 配布用の ZIP ファイルをダウンロードします。
2. WordPress 管理画面の「プラグイン」→「新規プラグインを追加」を開きます。
3. 画面上部の「プラグインをアップロード」をクリックし、手順 1 の ZIP ファイルを選んで「今すぐインストール」を実行します。
4. インストール後に表示される「プラグインを有効化」をクリックします。
5. 「設定」→「PageGuard」から、保護する投稿タイプなどを設定します。

## 動作要件

| 項目 | 必要なバージョン |
|---|---|
| WordPress | 6.7 以上 |
| PHP | 7.4 以上 |

外部のライブラリやサービスには依存しません。
